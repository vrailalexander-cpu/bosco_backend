# Django-проєкт Warehouse

## Інформація про студента

- **Група:** ІТ-22
- **Номер у групі:** 2

## Опис проєкту

Це Django-проєкт для роботи з товарами на складі.
Проєкт містить модель товару, сторінку зі списком товарів,
форму додавання нового товару, шаблони, власні template tags
та статичні CSS-файли.

## Структура проєкту

### `warehouse/`

Основна папка Django-проєкту.

### `catalog/`

Основний Django-застосунок для роботи з товарами.

- `migrations/` — файли міграцій бази даних.
- `static/` — статичні файли застосунку.
  - `catalog/` — папка зі статичними файлами застосунку.
    - `css/` — CSS-файли.
      - `style.css` — стилі для меню, таблиці та інших елементів сторінки.
- `templates/` — шаблони HTML для застосунку.
  - `catalog/` — шаблони застосунку.
    - `about.html` — сторінка «Про нас».
    - `add_product.html` — форма додавання нового товару.
    - `home.html` — головна сторінка.
    - `products.html` — сторінка зі списком товарів.
- `templatetags/` — власні Django template tags і filters.
  - `__init__.py` — визначає папку як Python-пакет.
  - `catalog_extras.py` — власний фільтр для ціни та тег для підрахунку товарів.
- `__init__.py` — визначає `catalog` як Python-пакет.
- `admin.py` — налаштування моделі для Django Admin.
- `apps.py` — конфігурація Django-застосунку `catalog`.
- `models.py` — моделі бази даних, зокрема модель `Product`.
- `tests.py` — файл для тестів застосунку.
- `urls.py` — URL-маршрути застосунку.
- `views.py` — функції представлень та обробка запитів.

### `config/`

Основна конфігурація Django-проєкту.

- `__init__.py` — визначає `config` як Python-пакет.
- `asgi.py` — налаштування ASGI для запуску проєкту.
- `settings.py` — основні налаштування Django-проєкту.
- `urls.py` — головні URL-маршрути проєкту.
- `wsgi.py` — налаштування WSGI для запуску проєкту.

### `templates/`

Загальні HTML-шаблони, які використовуються всім проєктом.

- `partials/` — окремі фрагменти шаблонів.
  - `menu.html` — навігаційне меню.
  - `messages.html` — виведення повідомлень Django Messages.
- `base.html` — базовий шаблон сайту, який використовується іншими сторінками через `{% extends %}`.

### `db.sqlite3`

Файл локальної бази даних SQLite, у якому зберігаються товари та інші дані Django.

### `manage.py`

Основний файл для виконання команд Django, наприклад:

```bash
python manage.py runserver
python manage.py makemigrations
python manage.py migrate
